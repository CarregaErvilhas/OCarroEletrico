Custo de carregar em cada posto MOBI.E, só com a parte do operador do posto (OPC), ordenado do mais barato para o mais caro. Não inclui a energia do teu CEME: para o custo total usa o [ohmigo](https://ohmigo.ocarroeletrico.com/). Cada lista existe em CSV, HTML e Markdown, para todo o país e só para o Porto.
